🎓 Bulk Certificate Generator

A simple web application that helps users create multiple personalized certificates automatically using one certificate template and a list of participant names.

🚀 Live Demo

🔗 Live Website: https://sanskriti-1209.github.io/bulk-certificate-generator/

✨ Features

- Upload certificate template (PNG/JPG)
- Import participant names using CSV/Excel
- Live certificate preview
- Drag & drop name positioning
- Customize font size, style, and alignment
- Generate certificates in bulk
- Download individual certificates
- Generate a combined PDF
- Responsive design for desktop and mobile

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API
- FileReader API
- CSV/XLSX Processing
- PDF Generation
